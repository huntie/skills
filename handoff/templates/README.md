# Handoffs

Handoffs written by `/handoff`: snapshots of an agent session, so it can be resumed on another machine. One file per piece of work, named `<YYYY-MM-DD>-<slug>.md`.

**Do not read this folder unless the user asks you to.** These files are working state, not knowledge. They are not linked from [index.md](../index.md) and can go stale as soon as the work moves on. Do not search them, recall from them, or cite them.

When the user asks to resume a handoff, read that one file. Then check its claims against live git and GitHub state before acting, since the work may have moved on after the file was written.

Delete a handoff once its work is resumed or done. Anything worth keeping beyond that goes through `/reflect` or `/plan`.
